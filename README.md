# 13枠カードゲーム

2人用オリジナルカードゲーム（ルールは [rules.md](rules.md)）を、ブラウザでオンライン対戦できるようにしたものです。

**遊ぶ:** https://hibiki5201.github.io/CardGame/

## 遊び方

1. 「部屋を作る」を押し、表示された URL を相手に送る
2. 相手がその URL を開いて「参加する」を押すと対戦開始
3. 「ローカル対戦」なら1台の端末で2人交代で遊べます

ルール設定（手札枚数・ジョーカー枚数・得点・交換コスト・先取数）は部屋を作る側が変更できます。

## しくみ（サーバー代ゼロ）

- 静的ファイルを GitHub Pages で配信するだけで、自前のサーバーはありません。
- 通信は WebRTC の P2P（[PeerJS](https://peerjs.com/)）。最初の接続の仲介だけ PeerJS の無料公開シグナリングサーバーを使い、以降のゲームデータはブラウザ同士で直接やり取りします。
- 部屋を作った側（ホスト）がルール判定と山札を管理し、相手には山札の中身を除いた状態だけを送ります。
- どちらかがリロードしても、同じタブなら対戦を再開できます。

### 注意

- 対称型 NAT など一部のネットワーク環境（会社や学校の回線、一部のモバイル回線）では P2P 接続できないことがあります。TURN サーバーは有料になりやすいため使っていません。つながらない場合は別の回線（Wi-Fi ⇔ モバイル）を試してください。
- PeerJS の公開サーバーは無保証の無料サービスです。

## 開発

ビルド不要です。任意の静的サーバーで開けます。

```bash
npx http-server -p 8080 -c-1 .
```

エンジンのテスト（ランダム対戦で不変条件をチェック）:

```bash
node tests/engine.test.mjs
```

| ファイル | 内容 |
| --- | --- |
| `js/game.js` | ルールエンジン（純粋関数） |
| `js/net.js` | PeerJS による P2P 通信 |
| `js/main.js` | 画面描画と操作 |
