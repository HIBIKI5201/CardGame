# 13枠カードゲーム

> **このゲームは、Warframe に登場するゲーム「Portau」をもとにした二次創作です。**
> 原作に関する権利は Warframe および Digital Extremes Ltd. に帰属します。
> 本作は非公式のファン作品であり、Digital Extremes Ltd. とは関係ありません。

2人用カードゲーム（ルールは [rules.md](rules.md)）を、ブラウザでオンライン対戦できるようにしたものです。

**遊ぶ:** https://hibiki5201.github.io/CardGame/

## 遊び方

1. 「部屋を作る」を押し、表示された URL を相手に送る
2. 相手がその URL を開いて「参加する」を押すと対戦開始
3. 「ローカル対戦」なら1台の端末で2人交代で遊べます

ルール設定（手札枚数・ジョーカー枚数・得点・交換コスト・先取数）は部屋を作る側が変更できます。

## しくみ（サーバー代ゼロ）

- 静的ファイルを GitHub Pages で配信するだけで、自前のサーバーはありません。
- 通信は WebRTC の P2P（[PeerJS](https://peerjs.com/)）。最初の接続の仲介だけ PeerJS の無料公開シグナリングサーバーを使い、以降のゲームデータはブラウザ同士で直接やり取りします。
- 部屋を作った側（ホスト）がルール判定と山札を管理し、相手には山札の中身を除いた状態だけを送ります。
- どちらかがリロードしても、同じタブなら対戦を再開できます。

## 無料で使える範囲と、超えたときに起きること

**どのサービスにも支払い方法を登録していないので、使いすぎても料金は発生しません。** 上限を超えた場合は課金されるのではなく、サービスが止まったり制限されたりします。

| 使っているもの | 用途 | 無料の範囲 | 超えた・落ちたときに起きること |
| --- | --- | --- | --- |
| GitHub Pages | ページの配信 | 公開リポジトリなら無料。サイトは 1 GB まで、転送量は月 100 GB が目安（ソフトリミット）、ビルドは 1 時間に 10 回が目安 | ページを開けなくなることがあります（HTTP 429 など）。GitHub から負荷を減らすよう連絡が来ることもあります |
| PeerJS 公開サーバー（0.peerjs.com） | 部屋を作る・参加するときの相手探し | 無料。上限や稼働保証は公開されていません | 停止・混雑中は部屋を作れず、参加もできません。接続済みの対戦はそのまま続きますが、切断後の再接続はできません |
| Google の STUN サーバー | P2P 接続のための自分のアドレス確認 | 無料。上限は公開されていません | 使えないと P2P 接続に失敗しやすくなります |

### どれくらい遊べるか

- GitHub Pages から配信するのは HTML・CSS・JS（同梱の PeerJS を含む）の約 140 KB だけです。月 100 GB の目安で換算すると、**ページを開く回数で月 70 万回程度**になります。ブラウザのキャッシュが効くので、実際にはもっと余裕があります。個人や友人同士で遊ぶ規模なら、まず届きません。
- 対戦中のデータ（カードの操作など）はブラウザ同士で直接やり取りするので、GitHub の転送量には含まれません。
- PeerJS 公開サーバーには数値の上限が公開されていません。多くの人が使う共有サーバーなので、混雑や停止がいちばん起きやすいのはここです。

### 止まったときの対処

- **PeerJS 公開サーバーが使えない:** しばらく待つか、[peerjs-server](https://github.com/peers/peerjs-server) を自分で立てて `js/net.js` の `new Peer(...)` に接続先を指定します（この場合はサーバーの運用が必要です）。
- **GitHub Pages の制限にかかった:** 時間をおくと戻ることが多いです。恒常的に超える規模になったら、Cloudflare Pages など別の無料ホスティングへの移行を検討します。

### つながらないとき

- 対称型 NAT など一部のネットワーク環境（会社や学校の回線、一部のモバイル回線）では P2P 接続できないことがあります。これを避けるには中継用の TURN サーバーが必要ですが、TURN は通信量に応じて有料になりやすいため使っていません。つながらない場合は別の回線（Wi-Fi ⇔ モバイル）を試してください。

（上限の数値は 2026年11月時点の [GitHub Pages の制限](https://docs.github.com/ja/pages/getting-started-with-github-pages/github-pages-limits) によります。）

## 開発

ビルド不要です。任意の静的サーバーで開けます。

```bash
npx http-server -p 8080 -c-1 .
```

エンジンのテスト（ランダム対戦で不変条件をチェック）:

```bash
node tests/engine.test.mjs
```

| ファイル | 内容 |
| --- | --- |
| `js/game.js` | ルールエンジン（純粋関数） |
| `js/net.js` | PeerJS による P2P 通信 |
| `js/main.js` | 画面描画と操作 |
| `vendor/peerjs.min.js` | PeerJS 1.5.4（MIT ライセンス、`vendor/peerjs.LICENSE`）。外部 CDN に頼らないよう同梱 |
